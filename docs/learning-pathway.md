# AI Engineering Learning Pathway

This pathway is designed to build practical AI engineering ability through a loop:

```text
learn -> predict -> build -> verify -> explain -> publish
```

## Direction

The goal is to become a strong young AI engineering builder, not just a course collector. Each module should produce visible evidence: code, tests, notes, reflections, screenshots, run logs, or project writeups.

| Module 10 | Capstone | Portfolio-ready flagship project |

## Standards For Each Project

Each serious project should include:

- `README.md`
- `.gitignore`
- dependency file such as `requirements.txt` or `pyproject.toml`
- clear setup and run instructions
- example input and output
- tests or a clear manual verification note
- architecture explanation
- reflection note
- safety and privacy note
- honest limitations
- AI assistance disclosure
